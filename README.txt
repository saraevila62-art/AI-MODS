MIYU — мод-компаньон для Minecraft 1.21.1 (NeoForge 21.1.209+, Java 21)

СБОРКА
1. Установите JDK 21 и Gradle 8.8+ (или откройте папку в IntelliJ IDEA — она подтянет Gradle сама).
2. В папке проекта:  gradle wrapper   затем   ./gradlew build   (Windows: gradlew.bat build)
3. Готовый мод: build/libs/miyu-1.0.0.jar — положите в mods/ рядом с LovsPlayer.
   (Для проверки без установки: ./gradlew runClient)

ЗАПУСК
1. В игре: творческий режим → вкладка «Яйца призыва» → «Яйцо призыва: Мию». Призовите её.
2. ПКМ по Мию — она станет вашей, и откроется меню. Повторный ПКМ — снова меню.
3. «Приказы»: следовать / ждать / телепорт к вам. Она ходит за вами сама.
4. Чтобы она отвечала: запустите игру один раз, закройте, откройте config/miyu-client.toml,
   впишите apiKey = "sk-ant-..." (ключ с console.anthropic.com, платный). Модель: claude-haiku-5-5 (дешевле).
   Ответы показываются в меню и дублируются в чат.

ВАЖНО
- Ключ хранится в открытом виде в конфиге: не отправляйте файл другим.
- «Одержимость» и «Здоровье» хранятся только на время сессии.
- «Переодеть», «Инвентарь», «Настройки» — заглушки. Скин один: textures/entity/miyu.png.
- Анимации LovsPlayer на Мию не действуют — это отдельный мод.

СБОРКА БЕЗ УСТАНОВКИ ПРОГРАММ (GitHub)
1. Создайте бесплатный аккаунт на github.com → New repository → загрузите ВСЁ содержимое папки miyu-mod
   (вместе со скрытой папкой .github).
2. Вкладка Actions → build → дождитесь зелёной галочки (2–5 минут).
3. Откройте запуск → внизу Artifacts → miyu-jar → скачайте архив, внутри miyu-1.0.0.jar.
4. Положите .jar в mods вашей сборки (туда же, где LovsPlayer).
